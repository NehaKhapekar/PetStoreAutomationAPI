# PetStoreAutomationAPI
A Java-based API automation framework for the Pet Store application using RestAssured, TestNG, and Maven. Designed with a modular and reusable architecture to support scalable API testing, data-driven testing, logging, reporting, and CI/CD integration.

Overview

This project is an API Automation Framework developed for testing the Pet Store REST APIs using Java, RestAssured, TestNG, and Maven.

The framework follows a modular and reusable design approach to make API automation easy to maintain, scalable, and easy to extend with new test scenarios.

Tech Stack
* Java – Programming language
* RestAssured – REST API automation
* TestNG – Test execution and test management
* Maven – Build and dependency management
* JSON – Request payloads and test data
* Log4j2 – Logging
* Extent Reports – Test reporting
* GitHub Actions – CI/CD
